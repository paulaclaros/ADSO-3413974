# Aspectos transversales

## Seguridad

El sistema tendrá acceso mediante usuario y contraseña.

Los permisos dependerán del rol:

Administrador:
- Control total del sistema.

Cajero:
- Registrar ventas y consultar información.


## Auditoría

El sistema podrá guardar información de operaciones importantes como ventas y cambios realizados.


## Disponibilidad

El sistema requiere conexión a internet para funcionar.


## Usabilidad

La interfaz debe ser sencilla para que los usuarios puedan aprender a utilizarla fácilmente.
