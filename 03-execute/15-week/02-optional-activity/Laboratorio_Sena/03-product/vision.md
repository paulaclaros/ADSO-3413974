# Visión del producto

## Nombre del producto

Sistema de Gestión - Supermercado La Esquina

## Propósito

Desarrollar un sistema web que permita al Supermercado La Esquina organizar y controlar sus procesos principales como ventas, inventario, clientes, fiados y pedidos a proveedores.

## Problema que resuelve

Actualmente el supermercado maneja la información manualmente mediante cuadernos, lo que genera errores en ventas, pérdida de información, falta de control del inventario y problemas con las cuentas por cobrar.

## Beneficios del sistema

- Mejor control de productos disponibles.
- Registro organizado de ventas.
- Reducción de errores en cobros.
- Control de clientes con fiados.
- Información disponible para tomar decisiones.

## Usuarios objetivo

Administrador:
Gestiona productos, usuarios, reportes y configuración.

Cajero:
Registra ventas y consulta información necesaria para atender clientes.
