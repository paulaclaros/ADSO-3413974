# Estrategia de migración de datos

## Situación actual

Actualmente el supermercado maneja información manualmente mediante cuadernos, libretas de fiados y registros físicos.

## Proceso de migración

1. Identificar la información existente.
2. Organizar productos, clientes y ventas.
3. Registrar la información en la base de datos.
4. Verificar que los datos sean correctos.
5. Iniciar el uso del sistema digital.


## Datos principales a migrar

- Productos disponibles.
- Clientes frecuentes.
- Cuentas pendientes.
- Información básica del negocio.
