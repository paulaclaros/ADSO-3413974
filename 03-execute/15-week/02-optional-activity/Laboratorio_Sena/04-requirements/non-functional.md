# Requisitos no funcionales

Los requisitos no funcionales indican cómo debe funcionar el sistema.

| ID | Requisito | Descripción |
|---|---|---|
| RNF-01 | Usabilidad | La interfaz debe ser sencilla y fácil de utilizar para los usuarios. |
| RNF-02 | Compatibilidad | El sistema debe funcionar en navegadores como Chrome, Firefox y Edge. |
| RNF-03 | Rendimiento | Las pantallas deben cargar rápidamente para mejorar la experiencia del usuario. |
| RNF-04 | Seguridad | El sistema debe proteger el acceso mediante usuario y contraseña. |
| RNF-05 | Disponibilidad | El sistema requiere conexión a internet para funcionar. |
