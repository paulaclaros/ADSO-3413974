# Requisitos funcionales

Los requisitos funcionales describen las funciones que debe realizar el sistema.

| ID    |          Requisito       |                            Descripción                                           | Prioridad |
|---|---|---|---|
| RF-01 | Registro de ventas       | El sistema debe permitir registrar ventas con fecha, productos y total calculad automáticamente.                                                                                                      | Alta |
| RF-02 | Control de inventario    | El sistema debe permitir crear, modificar y consultar productos con sus cantidades disponibles. | Alta |
| RF-03 | Alertas de stock         | El sistema debe avisar cuando un producto llegue al límite mínimo de inventario. | Alta |
| RF-04 | Cuentas por cobrar       | El sistema debe registrar fiados con cliente, fecha, valor y estado de pago.     | Alta |
| RF-05 | Inicio de sesión         | El sistema debe solicitar usuario y contraseña para ingresar.                    | Alta |
| RF-06 | Gestión de usuarios      | El administrador podrá crear usuarios y asignar roles.                           | Alta |
| RF-07 | Cálculo de cambio        | El sistema debe calcular automáticamente el cambio al realizar una venta.        | Alta |
| RF-08 | Gestión de pedidos       | El sistema debe permitir registrar pedidos a proveedores.                        | Media|
| RF-09 | Reportes                 | El sistema debe mostrar reportes de ventas e inventario.                         | Media|
| RF-10 | Actualización de precios | El administrador podrá modificar precios de productos.                           | Media|
