# Despliegue del sistema

## Tipo de implementación

El sistema será desplegado como una aplicación web.

## Requisitos

- Servidor para alojar la aplicación.
- Base de datos.
- Conexión a internet.
- Navegador web actualizado.

## Acceso

Los usuarios podrán ingresar mediante un navegador utilizando sus credenciales.

## Ambientes

### Desarrollo

Ambiente utilizado para crear y probar el sistema.

### Producción

Ambiente donde el supermercado utilizará el sistema diariamente.
