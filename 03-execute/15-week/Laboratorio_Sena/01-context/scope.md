# Alcance del proyecto

## En alcance

El sistema de gestión del Supermercado La Esquina incluirá:

- Registro de ventas con cálculo automático del total.
- Control y actualización del inventario de productos.
- Alertas cuando un producto llegue al stock mínimo.
- Registro y seguimiento de cuentas por cobrar (fiados).
- Gestión de pedidos a proveedores.
- Generación de reportes de ventas e inventario.
- Manejo de usuarios con roles de administrador y cajero.

## Fuera de alcance

Para la primera versión del sistema no se incluirá:

- Facturación electrónica DIAN.
- Aplicación móvil.
- Pagos electrónicos como tarjeta o Nequi.
- Funcionamiento sin conexión a internet.
- Integración con otros sistemas externos.

## Supuestos

- Los usuarios tendrán acceso a internet para utilizar el sistema.
- El administrador proporcionará la información de productos, precios y usuarios.
- Los empleados tendrán conocimientos básicos para usar una aplicación web.
- La información registrada en el sistema será responsabilidad del negocio.

## Restricciones

- El sistema funcionará únicamente mediante navegador web.
- Se requiere conexión a internet.
- Los permisos dependerán del rol del usuario.
- La primera versión tendrá funciones limitadas y podrá ampliarse después.
