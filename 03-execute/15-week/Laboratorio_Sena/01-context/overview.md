# Overview

## Nombre del proyecto
Sistema de Gestión - Supermercado La Esquina

## Descripción del proyecto
El proyecto consiste en desarrollar un sistema web para el Supermercado La Esquina, con el objetivo de mejorar el control de ventas, inventario, cuentas por cobrar, pedidos a proveedores y generación de reportes.

## Problema identificado
Actualmente el supermercado realiza sus procesos de forma manual mediante cuadernos y libretas, causando errores en ventas, pérdida de información, falta de control del inventario y desorganización de los fiados.

## Objetivo
Crear una solución digital que permita administrar los procesos principales del supermercado de manera rápida, organizada y segura.

## Usuarios principales
- Administrador: controla productos, usuarios, reportes y configuración.
- Cajero: registra ventas y consulta información.
